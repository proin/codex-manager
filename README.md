# Codex Account Manager

여러 Codex 계정의 사용량, 크레딧, 초기화권과 SSH 호스트의 Codex 설치 상태를 관리하는 개인용 macOS·Windows 앱이다. 좌측 메뉴에서 **계정관리**와 **호스트관리**를 선택한다.

## 실행

소스에서 실행하거나 설치파일을 만들려면 Node.js 22.12 이상과 npm이 필요하다. 설치파일로 앱을 설치한 컴퓨터에는 Node.js가 필요하지 않다.

```sh
npm install
npm start
```

개발 중에는 `npm run dev`를 실행한다. `npm run pack`으로 앱을 만들면 `release/mac-arm64/Codex Account Manager.app`에 저장된다. 컴퓨터에 설치된 Codex 실행 파일을 사용한다.

## 설치파일

```sh
npm run dist:mac
npm run dist:win
```

macOS 설치파일은 `release/installers/mac`에 저장한다. Apple Silicon용 `mac-arm64.dmg`와 Intel용 `mac-x64.dmg`를 제공한다. 파일을 열고 **Codex Account Manager**를 **Applications**로 드래그한다.

Windows x64 설치파일은 `release/installers/windows`의 `windows-x64-setup.exe`이다. 설치파일을 실행하고 설치 위치를 선택한다. 시작 메뉴와 바탕화면에 앱 바로가기를 만든다. 앱을 제거해도 계정 데이터는 유지한다.

파일명에는 앱 이름과 버전이 포함된다. 두 빌드 명령은 기존 `release/mac-arm64` 실행 앱을 덮어쓰지 않는다. macOS 설치파일은 macOS에서 생성하며, Windows 설치파일은 macOS에서도 생성할 수 있다. 아이콘과 앱 버전 정보를 포함하고, Windows 서명은 생략한다.

배포 인증서가 없는 설치파일이다. macOS에서 실행이 차단되면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 사용한다. Windows에서 SmartScreen이 실행을 차단하면 **추가 정보 → 실행**을 선택한다. Windows 설치 및 실행 검사는 Windows 컴퓨터에서 별도로 수행한다.

앱 실행 전에 Codex CLI를 설치한다. Windows의 호스트관리에는 OpenSSH 클라이언트가 필요하며 SSH 키 인증을 사용한다. Windows에서는 앱의 비밀번호 입력을 통한 키 등록을 지원하지 않는다. 공개 키를 서버에 먼저 등록한 뒤 호스트를 조회한다.

## 사용

1. **계정 추가**에서 이름과 로그인 방법을 선택하고 로그인한다. 브라우저가 열리면 추가할 ChatGPT 계정을 선택한다.
2. **전체 조회**를 누르면 계정별 남은 사용량, 다음 충전 시간, 크레딧, 초기화권 수가 표시된다. 받지 못한 값은 `—`로 표시한다.
3. 계정의 초기화권 수 또는 **초기화권 사용**을 누르면 보유 목록이 열린다. 발급일, 만료일, 사용 가능 상태를 확인하고 사용할 항목 1개를 선택한다. **선택 완료**를 누른 뒤 확인 알림에서 **사용**을 누르면 선택한 초기화권을 적용한다. **목록으로 돌아가기**로 선택을 바꾸거나 **취소**로 종료할 수 있다.
4. 여러 계정에 적용하려면 계정을 선택한 뒤 **초기화권 사용**을 누른다. 계정별로 사용할 초기화권을 선택한다. 항목을 선택한 계정에만 적용한다.
5. 계정의 **상세 통계**를 열면 최근 7일·30일·90일의 토큰 사용량과 잔여량 변화를 볼 수 있다. 일별·주별·월별 표시를 선택하고 **통계 새로 조회**로 사용량을 다시 가져온다. 초기화권 사용 기록도 같은 화면에 표시된다.

크레딧 잔액과 초기화권 수는 별도로 표시한다. 조회에 실패한 계정은 다른 계정의 조회를 막지 않는다. 계정 메뉴에서 이름 변경, 다시 로그인, 삭제를 할 수 있다.

초기화권 목록을 열면 서버에서 다시 조회한다. 만료되었거나 사용된 초기화권은 선택할 수 없다. 상세 목록을 받지 못한 경우 보유 수량과 안내를 표시한다. 목록이 일부만 제공되더라도 표시할 항목을 임의로 만들지 않는다.

토큰 사용량은 백만 토큰을 뜻하는 `M` 단위로 표시한다. `1M`은 1,000,000토큰이며 소수점은 최대 두 자리까지 표시한다. 예를 들어 1,234,600토큰은 `1.23M`, 12,000,000토큰은 `12M`으로 표시한다. 0보다 크고 10,000토큰보다 작은 값은 `<0.01M`, 0토큰은 `0M`, 받은 값이 없는 날짜는 `—`로 표시한다. 합계는 저장된 원래 토큰 수를 모두 더한 뒤 M 단위로 표시한다. 크레딧 잔액, 사용 비율, 초기화권 수는 정수로 표시한다.

응답이 끊긴 초기화 요청은 **결과 다시 확인**을 누르고 알림에서 **계속**을 선택한다. 같은 초기화권과 요청 번호로 처리해 중복 사용을 막는다. 초기화는 완료되었으나 사용량 조회가 실패한 경우에는 **사용량 다시 조회**를 누른다.

## 호스트관리

remote-mgmt와 같은 `~/.ssh/config`에서 호스트 목록을 읽는다. 이 앱에서 호스트를 추가·수정·삭제하면 remote-mgmt에도 같은 설정이 반영된다. 주석과 추가 SSH 옵션은 유지한다. 다른 프로그램이 설정을 변경한 뒤에는 목록을 다시 읽고 저장한다.

**새로고침**은 SSH 설정에서 목록을 다시 읽고 접속 상태, Codex 버전과 로그인 계정을 함께 조회한다. 호스트를 선택하면 **선택 업그레이드**와 **선택 삭제**가 새로고침 왼쪽에 표시된다. 관리 버튼은 한 줄로 표시한다.

목록에서 호스트별 접속 상태, Codex 버전, 로그인 계정을 한 줄로 표시한다. 접속 실패에 마우스를 올리거나 키보드로 선택하면 오류 내용이 표시된다. 조회 시간, 요금제와 작업 완료 문구는 표에 표시하지 않는다. 왼쪽 손잡이를 드래그하면 호스트 순서를 변경할 수 있다. 변경한 순서는 SSH 설정 파일의 주석에 저장하며, SSH가 사용하는 Host 항목 순서와 접속 옵션은 유지한다. **업그레이드**를 누르면 대상 호스트를 표시하고, 알림에서 실행을 선택하면 해당 호스트의 Codex를 업데이트한다. npm 또는 Homebrew로 설치된 Codex를 지원하며, 그 밖의 설치 방식은 안내를 표시한다.

**계정 전환**을 누르면 선택한 서버의 Codex 로그인 모달이 열린다. **로그인 시작**을 누르고 표시된 인증 코드를 복사한 뒤 **로그인 페이지 열기**로 브라우저에서 사용할 ChatGPT 계정에 로그인한다. 인증을 완료하면 서버의 Codex 계정과 목록의 계정명을 다시 조회한다. 로그인 중에는 취소할 수 있다. 기존 계정을 먼저 로그아웃하지 않으며, 인증 파일이나 토큰을 이 컴퓨터로 복사하지 않는다. device-auth 로그인은 ChatGPT 보안 설정 또는 워크스페이스 권한에서 허용되어 있어야 한다. [OpenAI 로그인 안내](https://learn.chatgpt.com/docs/auth#login-on-headless-devices)

**그룹 추가**로 호스트 그룹을 만든다. 그룹 이름 옆의 화살표로 목록을 펼치거나 접는다. 호스트 추가·수정 화면에서 그룹을 선택하거나, 호스트 손잡이를 그룹에 드래그하여 이동한다. **그룹 없음**으로 이동하면 그룹에서 빠진다. 그룹 이름 변경과 삭제를 지원하며, 그룹을 삭제해도 호스트는 유지한다. 그룹과 접기 상태는 SSH 설정 파일의 주석에 저장한다. 실제 SSH Host 항목 순서와 접속 옵션은 변경하지 않는다.

행의 체크박스로 호스트를 선택한다. **전체 선택**은 접힌 그룹의 호스트도 포함한다. **선택 업그레이드**를 누르고 대상 목록을 확인한 뒤 실행하면 모든 대상의 업그레이드를 동시에 시작한다. 각 호스트의 진행 상태와 버전을 표에 표시하며, 완료 후 성공과 실패 수를 표시한다. 메뉴를 전환한 후 돌아와도 진행 상태를 표시하고, 전체 작업이 완료될 때까지 대상 호스트의 중복 실행과 삭제를 막는다. 작업 중이거나 업그레이드할 수 없는 호스트는 실패 내용을 표시하고 다른 호스트는 계속 처리한다. 계정 전환은 호스트별로 실행한다.

**선택 삭제**는 대상 목록을 확인한 뒤 SSH 설정에서 선택한 호스트를 함께 삭제한다. 서버의 파일과 Codex 계정은 삭제하지 않는다. 선택한 호스트에서 작업이 진행 중이면 완료 후 삭제한다. 다른 프로그램에서 SSH 설정을 변경한 경우에는 목록을 다시 읽고 선택 항목을 확인한 뒤 다시 삭제한다.

호스트를 누르면 상세 모달이 열린다. **접속 정보** 탭에서 주소, 사용자, 포트, SSH 키 파일, 중간 접속 호스트와 Codex 정보를 표시한다. **키 등록** 탭은 remote-mgmt처럼 등록 대상, 등록 상태와 서버에 등록된 키를 나누어 표시한다. macOS에서는 접속에 필요한 비밀번호를 입력할 수 있다. 이 컴퓨터의 공개키와 일치하는 항목은 강조한다.

사용할 공개키가 없으면 키를 생성한다. **등록 상태 조회**로 등록 여부를 조회하고, **미등록 시 등록**을 누르면 등록 여부를 조회한 뒤 필요한 경우 서버의 `authorized_keys`에 추가한다. macOS에서 최초 접속에 비밀번호가 필요한 경우 키 등록 탭에서 입력한다. 비밀번호는 저장하지 않는다. 기존 개인키와 서버의 다른 공개키는 유지한다.

SSH에 저장된 호스트의 서버키가 일치해야 접속할 수 있다. 새 호스트는 터미널에서 SSH로 한 번 접속하여 서버키를 등록한 뒤 조회한다. `Host *`와 같은 공통 설정은 편집할 수 있으며 원격 실행 대상에서 제외한다.

## 저장

앱 데이터는 macOS에서 `~/Library/Application Support/Codex Account Manager`, Windows에서 `%APPDATA%\Codex Account Manager`에 저장한다. 계정마다 별도 로그인 저장소를 사용하고 로그인 정보는 운영체제의 인증정보 저장소에 저장한다. 기존 Codex의 로그인 정보와 대화는 변경하지 않는다.

계정을 삭제하면 이 앱에 저장된 해당 계정의 정보만 삭제한다. ChatGPT 계정은 삭제하지 않는다.

일별 토큰 사용량은 Codex 서버에서 제공하는 기록을 사용한다. 잔여량 변화와 초기화권 사용 기록은 이 앱이 기록을 시작한 시점부터 컴퓨터에 저장한다. 잔여량 조회 기록은 최근 90일을 보관한다. 초기화권 기록은 이 앱에서 처리 결과를 저장한 요청을 표시하며, 이전 버전의 데이터는 계정을 구분할 수 있는 최근 요청만 가져온다. 기록 시작 전의 잔여량이나 초기화권 사용 내역은 생성하지 않는다. 초기화 결과를 받지 못한 요청과 사용하지 않은 초기화권은 사용 수량에 더하지 않는다.

## 검사

```sh
npm test
npm run test:runtime
npm run test:electron
npm run test:ui
```

실제 초기화권은 검사에 사용하지 않는다. 화면 검사는 예시 계정과 호스트로 실행한다. 호스트 설정 검사는 임시 파일을 사용하며 실제 서버의 Codex 설치와 SSH 키는 변경하지 않는다. 연결 방식은 [connection.md](docs/connection.md)에 정리되어 있다.
